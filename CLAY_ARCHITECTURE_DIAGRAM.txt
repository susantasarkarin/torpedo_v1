COST TRACKING FLOW

Each operation that costs money:

1. PREVIEW EXECUTION
   - Estimated cost calculated upfront
   - No actual charge (dry-run)
   
2. IMPORT SESSION
   - Cost estimated based on record count
   - Shown in import gate before approval
   
3. COLUMN EXECUTION
   - Cost tracked per row
   - Logged to cost_ledgers
   - Subtracted from daily budget
   
4. DAILY/MONTHLY LIMIT
   - Check before each operation
   - Block if would exceed
   - Allow with approval if under

Cost Enforcement:

  Operation Start
        │
        ▼
  Calculate Cost
        │
        ▼
  Check Daily Budget
  ├─ Yes: Continue
  └─ No: Check manual override
        │
        ▼
  Execute Operation
        │
        ▼
  Log Cost
  └─ Update cost_ledgers
  └─ Update campaign total
        │
        ▼
  Check Monthly Budget
  ├─ Yes: Continue
  └─ No: Activate kill switch
