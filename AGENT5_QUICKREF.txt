┌─ STATISTICAL METHODS ──────────────────────────────────────────────────────┐
│                                                                            │
│ Chi-Squared Test:                                                          │
│   χ² = Σ((Observed - Expected)² / Expected)                               │
│   Tests if conversion rates differ significantly                          │
│   Threshold: p < 0.05 for significance                                    │
│                                                                            │
│ Z-Test for Proportions:                                                    │
│   z = (p₁ - p₂) / SE                                                      │
│   SE = sqrt(p_pool * (1-p_pool) * (1/n₁ + 1/n₂))                         │
│   Threshold: |z| > 1.96 for 95% confidence                                │
│                                                                            │
│ Wilson Score Confidence Interval:                                          │
│   CI = (p + z²/2n ± z*sqrt(...)) / (1 + z²/n)                            │
│   95% CI by default (z = 1.96)                                            │
│   More accurate than normal approximation                                 │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
