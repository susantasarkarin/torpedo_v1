🕐 SEND SCHEDULER - Quick Usage
───────────────────────────────────────────────────────────────────
from backend.campaigns import SendScheduler

scheduler = SendScheduler()

# Check if can send now
recipient = {'city': 'New York', 'state': 'NY', 'country': 'US'}
can_send, reason = scheduler.can_send_now(recipient)

# Get local time
local_time = scheduler.get_recipient_local_time(recipient)

# Check specific time
in_window = scheduler.is_within_send_window(local_time)

# Get next send window
next_window = scheduler.get_next_send_window(recipient)

# Custom send windows
can_send, reason = scheduler.can_send_now(
    recipient, 
    windows=[(8, 10), (13, 15), (17, 19)]  # 8-10am, 1-3pm, 5-7pm
)

🏥 DOMAIN HEALTH - Quick Usage
───────────────────────────────────────────────────────────────────
from backend.deliverability import DomainHealthService

service = DomainHealthService()

# Full health check (recommended)
result = service.calculate_health_score('example.com')
print(f"Score: {result['score']}/100 (Grade: {result['grade']})")

# Individual checks
spf = service.check_spf('example.com')
dkim = service.check_dkim('example.com', 'google')
dmarc = service.check_dmarc('example.com')
mx = service.check_mx_records('example.com')

# Auto-detect DKIM selectors
dkim_auto = service.check_dkim_auto('example.com')
print(f"Valid selectors: {dkim_auto['valid_selectors']}")

# Get recommendations
recommendations = service.get_recommendations(result)

💡 BEST PRACTICES
───────────────────────────────────────────────────────────────────
1. Always check domain health before starting campaigns
2. Use coordinates (lat/lng) for most accurate timezone
3. Set minimum health score threshold (recommend: 60+)
4. Monitor domain health weekly
5. Respect send windows for better engagement
6. Use DMARC policy 'quarantine' or 'reject'
7. Log timezone detection failures for review

⚠️ ERROR HANDLING
───────────────────────────────────────────────────────────────────
Both services return graceful failures:
• Timezone detection: Falls back to America/New_York
• Domain checks: Return status='error' with details
• All exceptions logged but don't crash
