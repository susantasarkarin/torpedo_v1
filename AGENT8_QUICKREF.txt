## SENTIMENT CLASSIFICATIONS

### Sentiment Values
- **positive**: Genuine interest or positive engagement
- **neutral**: Generic response without clear intent
- **negative**: Dismissive or rejection
- **unsubscribe**: Explicit opt-out request

### Intent Values
- **meeting_request**: Wants to schedule call/meeting/demo
- **more_info**: Requesting additional information
- **not_interested**: Explicitly not interested
- **wrong_person**: Reached wrong person
- **opt_out**: Explicit unsubscribe
- **general_inquiry**: General question
- **other**: Unclear intent

### Multi-Channel Sequence

```python
sequence = [
    {
        "day": 0,
        "channel": "linkedin",
        "linkedin_action_type": "connection_request",
        "connection_note": "Hi {{first_name}}, noticed your work in {{title}}..."
    },
    {
        "day": 2,
        "channel": "email",
        "template_id": "initial_outreach"
    },
    {
        "day": 5,
        "channel": "linkedin",
        "linkedin_action_type": "message",
        "message_content": "Following up on my connection request..."
    },
    {
        "day": 8,
        "channel": "email",
        "template_id": "follow_up_1"
    }
]

# Execute sequence
for step in sequence:
    await multi_executor.execute_step(step, recipient, campaign)
    await asyncio.sleep(step["day"] * 86400)  # Wait days between steps
```

## TROUBLESHOOTING

### LinkedIn Connection Not Sending
- Check LinkedIn service initialized
- Verify `linkedin_url` in recipient data
- Check daily rate limits haven't been exceeded
- Verify connection_note is not too long

### LinkedIn Message Not Sending
- Ensure connection first sent
- Check connection status is "accepted"
- Verify message_content provided
- Check daily message limits

### Sentiment Classification Failing
- Verify OPENAI_API_KEY set
- Check reply_text is not empty
- Confirm API key has sufficient credits
- Ensure reply_text is valid UTF-8

### Rate Limit Errors
- Check daily activity in linkedin_activity collection
- Verify session_id is correct
- Reset daily counters if needed
- Adjust daily_connection_limit / daily_message_limit
