# Image Assets

Place your images here:

## Required Images

### Logo
- `logo.png` - Main logo (recommended: 194x86px)
- `logo-white.png` - White version for dark backgrounds

### Hero Section
- `hero-visual.png` - Main hero image (recommended: 600x600px)

### About Section
- `about-team.jpg` - Team photo (recommended: 500x500px)

### Blog Posts
Place in `blog/` subfolder:
- `post1.jpg`, `post2.jpg`, etc.

### Testimonials
Place in `testimonials/` subfolder:
- Avatar images for testimonial authors

### Client Logos
Place in `clients/` subfolder:
- Client company logos

### Team Members
Place in `team/` subfolder:
- Team member headshots

## Image Guidelines

1. Use WebP format when possible for better compression
2. Provide 2x versions for retina displays
3. Optimize images before uploading
4. Recommended tools: Squoosh, TinyPNG
