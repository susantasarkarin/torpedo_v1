API ENDPOINTS DELIVERED

🔍 DELIVERABILITY MONITORING (7 endpoints):

1. GET  /deliverability/domains
   → List all monitored domains

2. GET  /deliverability/domains/{domain}/health
   → Full DNS health check (SPF, DKIM, DMARC, MX)

3. POST /deliverability/domains/{domain}/check
   → Trigger manual health check

4. GET  /deliverability/gmail-accounts/usage
   → Gmail pool usage stats (X/2000 per account)

5. GET  /deliverability/reputation?days=7
   → Aggregated reputation metrics

6. GET  /deliverability/alerts
   → Active deliverability alerts

7. POST /deliverability/alerts/{alert_id}/resolve
   → Resolve alert

📊 CAMPAIGN ANALYTICS (4 endpoints):

1. GET  /campaigns/{id}/analytics/timeseries?interval=day
   → Time series data for charts

2. GET  /campaigns/{id}/analytics/funnel
   → Conversion funnel (Sent → Opened → Clicked → Replied)

3. GET  /campaigns/{id}/analytics/by-segment?segment_by=industry
   → Performance by segment (industry/seniority/title/size)

4. GET  /campaigns/{id}/analytics/engagement-heatmap
   → Opens/clicks by hour/day (7×24 matrix)
