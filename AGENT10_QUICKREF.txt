# AGENT 10 QUICK REFERENCE
# API Endpoints for Re-engagement, A/B Testing & LinkedIn

## 🎯 RE-ENGAGEMENT ENDPOINTS

### List Dormant Leads
```http
GET /campaigns/automation/leads/dormant?inactivity_days=30&page=1
```

### Create Re-engagement Campaign
```http
POST /campaigns/automation/campaigns/reengagement
Content-Type: application/json

{
  "lead_ids": ["64f1a2b3c4d5e6f7g8h9i0j1"],
  "strategy_type": "reset",
  "analyze_first": true,
  "from_mailbox_id": "mailbox_123"
}
```

### Enroll Single Lead
```http
POST /campaigns/automation/leads/{lead_id}/reengagement/enroll
Content-Type: application/json

{
  "campaign_id": "64f1a2b3c4d5e6f7g8h9i0j1",
  "custom_message": "Personalized message here"
}
```

### Get Timeline
```http
GET /campaigns/automation/campaigns/{campaign_id}/reengagement/timeline
```

## 🧪 A/B TESTING ENDPOINTS

### Setup Test
```http
POST /campaigns/{campaign_id}/ab-test/setup
Content-Type: application/json

{
  "test_name": "Subject Line Test V3",
  "variants": [
    {
      "variant_id": "A",
      "name": "Short Subject",
      "subject_line": "Quick question",
      "template_id": "template_abc"
    },
    {
      "variant_id": "B",
      "name": "Long Subject",
      "subject_line": "I noticed your company does X",
      "template_id": "template_xyz"
    }
  ],
  "focus_metric": "open_rate",
  "auto_select_winner": true
}
```

### Get Results (with AI analysis)
```http
GET /campaigns/{campaign_id}/ab-test/results?analyze_with_agent=true
```

### Declare Winner
```http
POST /campaigns/{campaign_id}/ab-test/declare-winner
Content-Type: application/json

{
  "winner_variant_id": "B",
  "reason": "40% higher open rate with statistical significance"
}
```

### Auto-Select Winner
```http
POST /campaigns/{campaign_id}/ab-test/auto-select
Content-Type: application/json

{
  "minimum_sample_size": 100,
  "significance_threshold": 0.95
}
```

## 🔗 LINKEDIN AUTOMATION ENDPOINTS

### Login
```http
POST /linkedin/session/login
Content-Type: application/json

{
  "email": "you@company.com",
  "password": "your_password",
  "headless": false
}
```

### Check Session
```http
GET /linkedin/session/status?email=you@company.com
```

### Logout
```http
DELETE /linkedin/session/logout?email=you@company.com
```

### Send Connection Request
```http
POST /linkedin/connections/send?email=you@company.com
Content-Type: application/json

{
  "lead_id": "64f1a2b3c4d5e6f7g8h9i0j1",
  "linkedin_url": "https://www.linkedin.com/in/johndoe",
  "connection_note": "Hi John, I noticed we both work in...",
  "custom_variables": {"source": "cold_outreach"}
}
```

### Bulk Connection Requests
```http
POST /linkedin/connections/send-bulk?email=you@company.com
Content-Type: application/json

{
  "connections": [
    {
      "lead_id": "lead1",
      "linkedin_url": "https://linkedin.com/in/user1",
      "connection_note": "Personalized note 1"
    },
    {
      "lead_id": "lead2",
      "linkedin_url": "https://linkedin.com/in/user2",
      "connection_note": "Personalized note 2"
    }
  ],
  "delay_between_requests": 45
}
```

### List Connections
```http
GET /linkedin/connections?status=pending&email=you@company.com&page=1
```

### Check Connection Status
```http
GET /linkedin/connections/{connection_id}/status
```

### Update Connection Status
```http
PATCH /linkedin/connections/{connection_id}/status
Content-Type: application/json

{
  "new_status": "accepted"
}
```

### Send Message
```http
POST /linkedin/messages/send?email=you@company.com
Content-Type: application/json

{
  "lead_id": "64f1a2b3c4d5e6f7g8h9i0j1",
  "connection_id": "64a9b8c7d6e5f4g3h2i1j0k9",
  "message_content": "Thanks for connecting! I wanted to..."
}
```

### Get Stats
```http
GET /linkedin/stats?email=you@company.com&date_range=today
```

### Daily Breakdown
```http
GET /linkedin/stats/daily-breakdown?email=you@company.com&days=7
```

## 🔑 KEY PARAMETERS

### Re-engagement
- `inactivity_days`: Minimum days inactive (default: 30)
- `strategy_type`: "reset", "soft_drip", or "trigger_based"
- `analyze_first`: Use ReengagementAgent (default: true)

### A/B Testing
- `focus_metric`: "open_rate", "click_rate", "reply_rate", "conversion_rate"
- `analyze_with_agent`: Get AI insights (default: false)
- `minimum_sample_size`: Min emails per variant (default: 100)
- `significance_threshold`: Confidence level (default: 0.95)

### LinkedIn
- `headless`: Run browser hidden (default: false for 2FA)
- `delay_between_requests`: Seconds between bulk sends (10-300)
- `date_range`: "today", "week", "month", "all"

---

## ⚠️ RATE LIMITS

### LinkedIn Daily Limits
- Connection Requests: **100/day**
- Messages: **50/day**
- Enforced at API level
- Returns 429 status when exceeded

---

## 🚨 ERROR CODES

- `400`: Invalid request parameters
- `401`: Authentication failed
- `404`: Resource not found
- `429`: Rate limit exceeded
- `500`: Internal server error

## 💡 COMMON USE CASES

### 1. Re-engage Cold Leads
```bash
# Get dormant leads
curl GET /leads/dormant?inactivity_days=45

# Create campaign with AI analysis
curl POST /campaigns/reengagement \
  -d '{"lead_ids": [...], "analyze_first": true}'
```

### 2. Run Subject Line Test
```bash
# Setup test
curl POST /campaigns/{id}/ab-test/setup \
  -d '{"variants": [...]}'

# Wait for data...

# Get results with AI insights
curl GET /campaigns/{id}/ab-test/results?analyze_with_agent=true

# Auto-select winner
curl POST /campaigns/{id}/ab-test/auto-select
```

### 3. LinkedIn Outreach Campaign
```bash
# Login once
curl POST /linkedin/session/login \
  -d '{"email": "...", "password": "..."}'

# Send bulk connections
curl POST /linkedin/connections/send-bulk \
  -d '{"connections": [...]}'

# Check stats
curl GET /linkedin/stats?date_range=today
```

```

3. API → Agent (optional analysis)
4. Agent → OpenAI (reasoning)
5. API → Database (save results)
6. API → Frontend (return response)
```
