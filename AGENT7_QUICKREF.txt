## Gmail Account Pool Manager

### Get Available Accounts
```python
from backend.campaigns.rate_limiter import RateLimitService
limiter = RateLimitService(db)
accounts = limiter.get_available_accounts(required_capacity=100)
```

### Select Best Account
```python
selected = limiter.select_best_account(accounts)
# Returns account with sends_today < 1600 (80% threshold)
```

### Get Pool Statistics
```python
stats = limiter.get_pool_stats()
# Returns: total_capacity, used, available, percentage_used, active_accounts
```

## LinkedIn Automation

### Initialize Service
```python
from backend.linkedin.service import LinkedInAutomationService
service = LinkedInAutomationService(db)
await service.initialize_session("email@example.com", headless=False)
```

### Login
```python
# First login (includes manual 2FA if needed)
await service.login("email@example.com", "password", headless=False)
# Subsequent runs use saved session cookies
```

### Send Connection Request
```python
result = await service.send_connection_request(
    profile_url="https://www.linkedin.com/in/username/",
    note="Let's connect!",
    lead_id="lead_123"
)
```

### Send Message
```python
result = await service.send_message(
    connection_name="John Doe",
    message="Hi John!",
    lead_id="lead_123"
)
```

### Check Daily Activity
```python
stats = await service.get_activity_stats()
# Returns: connections_sent, messages_sent, connections_remaining, messages_remaining
```

### Batch Send Connections
```python
from backend.linkedin.service import batch_send_connections

profiles = [
    {"profile_url": "...", "note": "...", "lead_id": "..."},
    {"profile_url": "...", "note": "...", "lead_id": "..."},
]

results = await batch_send_connections(
    db, email, profiles,
    delay_between=(30, 60)

```

## Configuration

```python
# Customize delays
delay_between=(45, 90)  # Slower: 45-90 seconds

# Customize storage
storage_dir="./custom_sessions"

# Headless vs headed
headless=True   # No visible browser
headless=False  # Visible browser (required for 2FA first login)
```

## Troubleshooting

**2FA Timeout:** Complete verification within 120 seconds  
**Not Logged In:** Check account status is "active" in DB  
**Rate Limit Hit:** Wait until next day (midnight UTC reset)  
**Session Expired:** Delete `linkedin_sessions/` folder  
**Bot Detection:** Increase delays, use VPN if needed
